# 已知限制（請務必閱讀）

本專案不假裝「完整支援」所有格式。以下是實際行為與限制。

## 轉換
| 項目 | 現況 | 建議 |
|---|---|---|
| **Office → PDF / PDF/A** | **不提供**：無法在瀏覽器端可靠實作，且為保持「檔案不上傳」已移除伺服器端轉檔。 | 請用 Office / LibreOffice 另存 PDF。 |
| **PDF → Word / Excel / PPT（本機）** | Word：只輸出文字與標題層級（無表格/圖片/版面）。Excel：依文字間距分欄，非真正表格辨識。PPT：每頁一張圖片投影片（外觀精確、不可編輯文字）。 | PDF 反向轉換本質上是有損的；要可編輯版面請用桌面 Office / LibreOffice 開啟 PDF。 |
| **PDF → HTML / Markdown** | 以字級與符號做啟發式判斷標題與清單，不處理多欄排版、表格、圖片。 | 當作內容擷取，不是版面還原。 |
| **TIFF** | 讀寫透過純 JS 解碼器，僅涵蓋常見的未壓縮 / LZW / 部分 JPEG 變體；多頁 TIFF 目前只讀第一頁。 | 大量 TIFF 請先轉 PNG。 |
| **WebP 輸出** | Safari 的 canvas 不支援輸出 WebP，會自動改為 PNG（副檔名會相應調整）。 | — |

## 壓縮
- 預設只**重新壓縮內嵌 JPEG 影像**（保留文字與向量）。Flate 編碼的點陣圖、CMYK JPEG、JPX 不會被處理。
- 「全頁點陣化」壓縮最強，但文字不可選取（可再 OCR）。

## OCR
- 引擎為 Tesseract（`best_int` 語言資料）：繁中/簡中/英文/日文。準確度受掃描品質、字型、傾斜、排版影響；手寫與直排辨識率低。**請人工校對重要內容**。
- 一次辨識多語言會變慢；iOS 上 200 DPI 以上的多頁文件可能耗盡記憶體，請分批。
- 輸出 PDF 以頁面影像為底 + 隱形文字層，檔案可能比原檔大。
- 「伺服器端大型 OCR」目前**未實作**（所有 OCR 均在瀏覽器執行）。

## 安全
- **加密**：AES-256（PDF 2.0 / R6），由 qpdf-wasm 在瀏覽器內完成。**權限旗標（禁止列印/複製）僅靠閱讀器自願遵守**，不是強制機制。
- **塗黑**：以「含塗黑區域頁面整頁點陣化」確保底層資料被移除；因此該頁文字不可選取。自動尋找敏感資訊（Email、電話、身分證…）是以文字位置**近似**計算矩形，請在畫面上人工確認；掃描檔需先 OCR。
- **數位簽章檢視**：只解析簽章欄位結構並偵測簽署後是否追加內容，**不做密碼學驗證與憑證鏈信任判斷**，不能據此宣稱簽章有效。
- **中繼資料移除**：移除 Info、XMP、PieceInfo 與 JPEG EXIF/IPTC；不處理嵌入檔案附件、隱藏圖層名稱、字型內嵌名稱等。需要完整消毒請搭配「塗黑」重建檔案。
- **功能開關**：工具的開關是「管理政策」，因為運算在使用者裝置上進行，懂技術的使用者可繞過 UI。

## 檢視器 / 平台
- 手機捏合縮放為 CSS 暫態縮放，放開手指後才重新繪製清晰度。
- iPhone Safari 不支援 Fullscreen API（iPad 支援），「全螢幕」按鈕在 iPhone 上會隱藏；請改用「加入主畫面」以獨立視窗開啟。
- 朗讀使用瀏覽器內建語音合成，語音品質與語言種類取決於裝置。
- 在**背景分頁**中，瀏覽器會嚴重節流計時器；長時間 OCR/批次處理時雖會繼續進行（已改用計時器排程繪製），但速度會變慢。
- iOS 記憶體限制：單張 canvas 以 ≈16M 像素為上限，並逐頁處理與釋放；超大檔案（> 100 MB）仍可能失敗，因為 pdf-lib 需要把檔案載入記憶體。
- pdf-lib 無法開啟的嚴重損毀檔案，需先使用「修復 PDF」。
- 簡易 TOTP 以 SHA-1 / 6 碼 / 30 秒實作（與 Google Authenticator 相容）。不提供備援碼，管理者可由 CLI 重設帳號。

## 帳號 / 後端
- 開發預覽預設使用內嵌的 PGlite（WASM 版 PostgreSQL）；**同一資料夾同時間只能被一個程序開啟**（執行 `admin:create` 前需先停掉伺服器）。正式環境請使用 `DATABASE_URL` 指向 PostgreSQL。
- 資料庫存取採**參數化 SQL**（`$1` 佔位），未引入 ORM。
- 郵件需自行設定 SMTP；未設定時註冊不需信箱驗證，且忘記密碼無法寄信。
- Service Worker 與 iOS「加入主畫面」需 HTTPS（`localhost` 除外）。

## 測試涵蓋
- 伺服器：Vitest + Supertest（認證、鎖定、refresh 旋轉與重放偵測、CSRF、RBAC、TOTP 強制設定、稽核日誌不可變、功能開關、上傳驗證）。
- 前端：PDF 運算層單元測試（頁碼範圍、合併/分割/整理/裁切/調整大小/修復、中繼資料移除、浮水印/頁碼/Bates、表單建立與填寫、書籤、連結、資訊、註解套用）。
- 瀏覽器端 UI 流程（合併、整理、加解密、塗黑、OCR、後台登入與強制設定）在開發時以真實瀏覽器手動驗證；**尚未建立自動化 UI E2E（Playwright）**。Docker 映像尚未在本機實際建置驗證。
